# Modern Optimization Plugin (community fork)

> **This is a maintained fork of [Athlon007/MOP](https://github.com/Athlon007/MOP).**
> The original project by Konrad Figura (Athlon007) stopped being maintained after version 3.10.4.
> This fork, maintained by [ThePotato456](https://github.com/ThePotato456), continues development:
> upgrading the build and mod-loader support and improving performance further.
>
> Work in progress. See [INVENTORY.md](INVENTORY.md) for a codebase overview and the upgrade roadmap.

MOP (Modern Optimization Plugin) is the ultimate performance enhancing project for My Summer Car. Quickly and easily improve FPS of MSC!

The **only** mod that improves framerate seamlessly, without the user having to do any configuration, press buttons, or perform any other magic tricks! Just install the mod and it's ready to go.

Originates from [KruFPS](https://github.com/Krutonium/KruFPS).

**Results may vary!**

## Requirements

- **Latest LEGAL COPY** of My Summer Car
- MSCLoader 1.2.8 (support for newer MSCLoader versions is planned for this fork)

## Installation

1. Download MOP from this fork's [Releases](https://github.com/ThePotato456/MOP/releases) (coming soon). The last original release (3.10.4) is still available from [Athlon007's releases](https://github.com/Athlon007/MOP/releases) and [NexusMods](https://www.nexusmods.com/mysummercar/mods/146/).
2. Navigate to your MSC Mod Loader Mods folder (ex. `C:\Steam\steamapps\common\My Summer Car\Mods`) and paste `MOP.dll` there.
3. ???
4. Profit!
